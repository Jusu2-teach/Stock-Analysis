## ⚠️ 工程提醒：避免过度拟合

> **核心原则：参数基于金融常识，不基于历史回测！**

### 风险警告
v3.1 引入了大量超参数（λ, κ, φ, ω, w₁, w₂...），如果在回测中"暴力搜索"最优解，
会得到一个在历史数据上完美但在未来失效的模型（Overfitting）。

### 对策
1. **不要训练参数** —— 这些参数必须基于金融常识和物理直觉设定
2. **使用先验参数** —— 文档给出的默认值（如 λ=0.8）已经过专家审核
3. **季度微调** —— 只在每季度进行 Calibration，而不是每天重训练

### 参数哲学
```python
# ✅ 正确做法：基于金融常识
lambda_risk = 0.8   # 资金成本膨胀系数，反映信用风险溢价

# ❌ 错误做法：暴力搜索
for lambda_risk in np.linspace(0.1, 2.0, 100):
    backtest(lambda_risk)  # 这是过度拟合！
```

## 🏗️ 上帝方程 III v3.0 (Structure Solver)

### 周期动态通道版

```
T_slope = [BaseSlope] × ChannelMultiplier × FraudPenalty
```

其中**基础斜率**:
```
BaseSlope = -0.02 + k₁(1-β) + k₃(γ×V_gate) - k₂×δ_decay×(1+ω×β)
```

### 核心创新

#### 1. 周期位置动态通道 (乘数而非加数)
```python
def compute_cycle_channel_multiplier(cycle_position, alpha):
    if cycle_position < 0.3:  # 底部
        boost = 0.5 × (0.3 - cycle_position) / 0.3
        return 1.0 + boost × alpha  # 最大 ×1.5
    elif cycle_position > 0.7:  # 顶部
        decay = 0.8 × (cycle_position - 0.7) / 0.3
        return 1.0 - decay × alpha  # 最小 ×0.2
    else:
        return 1.0  # 中部中性
```

**洞见**：周期底部放大正斜率预期，周期顶部压缩甚至转负。

#### 2. 拐点加速杀 (衰退×资产交互)

# v3.0: k₂ × δ_decay × (1 + ω×β)

|---------|-----|--------|
| 0.5     | 0.2 | 1.1x   |

| 0.8     | 0.8 | 1.4x   |

**洞见**：重资产公司的衰退斜率会更陡峭。

#### 3. 欺诈斜率惩罚
```python
def compute_fraud_slope_penalty(delta_fraud, threshold=0.3):
    if delta_fraud <= threshold:
        return 1.0
    excess = delta_fraud - threshold
    return max(0.0, 1.0 - excess / (1.0 - threshold))
```

**洞见**：造假公司的"改善斜率"不可信，大幅打折。
