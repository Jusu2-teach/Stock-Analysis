# AStock 综合研报生成引擎 (Comprehensive Reporting Engine)

> **版本**: 3.0 (2025-12)
> **定位**: 全方位公司评价系统
> **核心理念**: "4层过滤，找出3类真正无懈可击的好公司"

---

## 1. 模块简介 (Introduction)

本模块 (`reporters`) 是 AStock 系统的"输出端"，也是整个分析系统的**最终价值呈现层**。

### 1.1 设计哲学

我们有大量的分析工具（趋势分析、断点检测、贝叶斯概率、交叉验证等），但这些都是**手段**而非**目的**。

**最终目的只有一个：找出3类真正的好公司**

```
┌──────────────────────────────────────────────────────────────┐
│                    报告引擎核心目标                           │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   🚀 高成长优质公司 (GARP)     追求成长的进攻型投资者        │
│   🏰 白马护城河 (Quality)      追求稳健的长期投资者          │
│   🔄 困境反转 (Turnaround)     有耐心的逆向投资者            │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 架构演进

| 版本 | 特点 | 问题 |
|------|------|------|
| V1.0 | 单指标CSV输出 | 无综合评价 |
| V2.0 | 多板块报告 | 技术板块太多，用户困惑 |
| **V3.0** | **聚焦3类公司** | **所有分析都为最终筛选服务** |

## 3. 三类公司筛选标准 (Selection Criteria)

### 3.1 🚀 高成长优质公司 (GARP - Growth at Reasonable Price)

**投资逻辑**：寻找高增长的同时，确保增长质量和现金流健康。

**必须满足条件**：

| 维度 | 条件 | 原理 |
|------|------|------|
| 营收成长 | CAGR > 10% | 市场份额扩张 |
| 利润成长 | CAGR > 15% | 盈利能力提升 |
| 现金流 | OCF斜率 > -5% | 利润含金量高 |
| 恶化信号 | 恶化概率 < 50% | 无下行风险 |
| 规模 | ≥ 中型 (50亿+) | 流动性保障 |
| 交叉验证 | 全部通过 | 无财务造假嫌疑 |

**综合评分公式**：
```
综合评分 = 50% × 成长因子 + 30% × 质量因子 + 20% × 安全因子
```

### 3.2 🏰 白马护城河 (Quality Moat)

**投资逻辑**：寻找具有深厚护城河、极高资本回报率的行业龙头，适合长期持有。

**必须满足条件**：

| 维度 | 条件 | 原理 |
|------|------|------|
| ROIC | > 12% | 资本效率高 |
| ROE | > 15% | 股东回报好 |
| 毛利率 | > 25% | 有定价权 |
| 趋势稳定 | R² > 0.5 | 业绩可预测 |
| 杠杆检验 | ROE/ROIC < 2 | 非杠杆驱动 |
| 规模 | ≥ 中型 (50亿+) | 行业地位 |

**护城河评分公式**：
```
护城河分 = 60% × 质量因子 + 40% × 安全因子
```

**护城河特征识别**：
- 毛利率 > 40% → "定价权强"
- ROIC > 20% → "资本壁垒"
- ROE > 20% + ROIC > 15% → "盈利稳健"

### 3.3 🔄 困境反转 (Turnaround)

**投资逻辑**：寻找基本面触底回升的公司，高风险高回报。

**必须满足条件**：

| 维度 | 条件 | 原理 |
|------|------|------|
| 反转信号 | is_turnaround = 1 | 趋势策略确认 |
| 断点确认 | has_break = 1 (加分) | 结构性改善 |
| 近期改善 | 近3年斜率 > 0 | 向上动能 |
| 毛利保护 | 毛利率斜率 > -3% | 非降价清库存 |
| 规模 | ≥ 中型 (50亿+) | 降低破产风险 |

**反转信号强度**：
- ⭐ 强信号：has_break=1 + 近期斜率>0.1
- 📈 中信号：近期斜率>0.05
- 📊 弱信号：其他反转

**风险提示**：困境反转是高风险策略，建议仓位控制在10%以内。

## 4. 交叉验证详解 (Cross Validation Rules)

交叉验证是防止"纸上谈兵"的关键，通过比较相关指标识别财务异常：

### 4.1 纸面富贵检测
```python
if 利润斜率 > 15% and 现金流斜率 < -5%:
    风险 = "纸面富贵"
    # 利润通过赊销堆出来，实际收不到钱
```

### 4.2 低效扩张检测
```python
if 营收斜率 > 15% and ROE < 5%:
    风险 = "低效扩张"
    # 烧钱换增长，股东回报极低
```

### 4.3 杠杆陷阱检测
```python
if ROE > 15% and ROIC < 8%:
    风险 = "杠杆驱动"
    # 高ROE靠借债，实际资本效率差
```

### 4.4 费用失控检测
```python
if 毛利率斜率 > -2% and 净利率斜率 < -5%:
    风险 = "费用失控"
    # 产品赚钱但被费用侵蚀
```

## 6. 技术实现 (Implementation)

### 6.1 核心类

```python
# 报告生成器
from astock.business_engines.reporters.comprehensive_generator import (
    ComprehensiveReportGenerator
)

# 实例化
generator = ComprehensiveReportGenerator(data_dir="data/filter_middle")

# 生成报告
report = generator.generate_report(output_path="data/comprehensive_analysis_report.md")
```

### 6.2 关键方法

| 方法 | 功能 | 输出 |
|------|------|------|
| `_calc_growth_score()` | 计算成长因子 | 0-100分 |
| `_calc_quality_score()` | 计算质量因子 | 0-100分 |
| `_calc_safety_score()` | 计算安全因子 | 0-100分 |
| `_check_cross_validation()` | 交叉验证 | (是否通过, 风险列表) |
| `_check_turnaround_signals()` | 反转检测 | (是否反转, 原因) |
| `_check_deterioration_risk()` | 恶化风险 | (有风险, 概率) |
| `_select_garp_companies()` | 筛选GARP | DataFrame |
| `_select_quality_moat_companies()` | 筛选白马 | DataFrame |
| `_select_turnaround_companies()` | 筛选反转 | DataFrame |

### 6.3 Pipeline 集成

在 `workflow/analysis.yaml` 中配置：

```yaml
- name: "Generate_Comprehensive_Report"
  component: "business_engine"
  engine: "reporting"
  method: ["report_comprehensive"]
  parameters:
    data_dir: "data/filter_middle"
    output_path: "data/comprehensive_analysis_report.md"
  depends_on:
    - "store_ROIC_Trend"
    - "store_ROIIC_Trend"
    - "store_Revenue_Trend"
    - "store_Profit_Trend"
    - "store_GrossMargin_Trend"
    - "store_NetMargin_Trend"
    - "store_ROE_Trend"
    - "store_OCF_Trend"
```
