## 📖 方法论说明

### 4层过滤体系

```
第1层：基础质量过滤（整合趋势引擎评分）
  ├─ 趋势斜率（成长性）：OLS + Theil-Sen稳健斜率
  ├─ R²拟合度（稳定性）：趋势可靠性指标
  ├─ 波动率（风险）：CV + 去趋势CV
  ├─ 趋势评分（trend_score）：规则引擎综合评分
  └─ Mann-Kendall检验：非参数趋势检验

第2层：交叉验证（NaN安全处理）
  ├─ 利润 vs 现金流 → 剔除纸面富贵
  ├─ 营收 vs ROE → 剔除低效扩张
  ├─ ROE vs ROIC → 剔除杠杆驱动
  ├─ 毛利率 vs 净利率 → 验证费用控制
  ├─ 连续下跌年数 → 持续恶化检测
  ├─ 恶化加速度 → 加速下滑预警
  ├─ OLS vs 稳健斜率 → 异常值干扰检测
  ├─ fused_slope异方差 → 斜率稳定性验证
  └─ FFT周期底部 → 周期公司错杀保护

第3层：拐点检测（多维度恶化检测）
  ├─ 贝叶斯恶化概率 → 综合多信号量化风险
  ├─ Mann-Kendall趋势检验 → 统计显著性验证
  ├─ 结构断点检测 → 识别公司质变点
  ├─ 恶化模式(deterioration_pattern) → 分类恶化类型
  ├─ 恶化加速度 → 检测恶化是否加剧
  ├─ 波动率体制 → 识别波动扩大风险
  └─ 周期置信度(cyclical_confidence) → 周期公司特殊处理

第4层：综合评分 & 分类
  ├─ 🚀 高成长 (GARP)：成长60% + 质量25% + 安全15%
  ├─ 🏰 白马护城河：质量60% + 安全40%
  └─ 🔄 困境反转：反转信号 + 断点确认 + 毛利保护
```

### 专业统计方法

| 方法 | 用途 | 优势 |
|---|---|---|
| OLS回归 | 计算趋势斜率 | 经典方法，易解释 |
| Theil-Sen估计 | 稳健斜率 | 抗异常值，最多容忍29%异常 |
| Mann-Kendall | 趋势显著性 | 非参数检验，不假设分布 |
| 贝叶斯推断 | 恶化概率 | 综合多信号，量化不确定性 |
| CUSUM | 断点检测 | 识别结构性变化点 |
| FFT频谱分析 | 周期检测 | 识别主导周期长度 |
| 去趋势CV | 真实波动率 | 剔除趋势后的纯波动 |
| WLS/融合斜率 | 异方差处理 | 近期数据权重更高 |
